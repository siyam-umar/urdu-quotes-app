# 🌙 Urdu Quotes App  
A simple, beautiful and mobile-friendly web app that shows random Urdu quotes with animation, dark mode and share button.

---

## 📱 Live Demo  
[![Live Demo](https://img.shields.io/badge/Live-Demo-blue?style=for-the-badge)](https://siyam-umar.github.io/urdu-quotes-app/)

---

## ✨ Features

- ✔ **Mobile Friendly (349px optimized)**
- ✔ **Random Urdu Quotes**
- ✔ **Dark / Light Mode Toggle**
- ✔ **Smooth Fade Animations**
- ✔ **Share Button (WhatsApp + Copy text)**
- ✔ **Background Images Support**
- ✔ **Modern UI With Gradient Overlay**
- ✔ **Fast & Lightweight (Pure HTML, CSS, JS)**
